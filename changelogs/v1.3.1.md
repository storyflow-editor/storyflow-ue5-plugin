##### New Features

- **Dialogue Rollback**: Enable Dialogue Rollback in StoryFlow Editor's project settings, export again and the plugin keeps a bounded history of earlier dialogue steps. `GoBack` returns to the previous interaction and restores story globals and locals, script and loop positions, once-only choices, character values, Data Asset runtime writes and the story's random stream. Blueprints get **Go Back**, **Can Go Back**, **Get Rollback Availability** and **Block Rollback**, plus an availability event for enabling a button. A widget derived from the supplied dialogue widget base binds an optional button named **BackButton** automatically. Rollback is off by default and costs nothing while it is off

- **Block Rollback**: Call **Block Rollback**, or place the Block Rollback node in a story graph, before work that cannot be undone, such as granting an achievement or writing to a server. It clears the retained history, so Back cannot cross that point

- **MetaHuman Lip Sync**: `UStoryFlowMetaHumanLipsyncComponent` drives a MetaHuman face from the playing dialogue voice. An optional editor baking workflow prepares lip sync data for dialogue lines ahead of time; playback at runtime does not depend on it

- **Localized Data Asset Overrides**: A string a child Data Asset overrides is now translated like the declared value it replaces. Fields that opt out of localization in StoryFlow Editor stay as authored

- **Configurable Script Nesting Limit**: The maximum depth of Run Script calls follows the project's setting in StoryFlow Editor, so the plugin stops a runaway chain at the same depth the editor does

##### Improvements

- **Smoother Lip Sync Analysis**: The voice spectrum is smoothed before it drives the mouth, and the Synty Sidekick defaults are retuned for a steadier result

- **Refreshed Example Dialogue Widgets**: The example dialogue and button widgets ship with updated styling, fonts and materials

- **Error Reporting Matches StoryFlow Editor**: A missing script, a missing flow and a Start node with nothing connected now raise the same errors the editor shows. A Run Script with no script and a Run Flow with no flow only warn

##### Bug Fixes

- **For Each Loops Stopped After Their First Element**: A loop whose body ended on an unconnected Random Branch or Switch On Enum output, a Block Rollback node, an empty flow, an empty Loop Body or a Run Script with nothing connected after it stalled on the first element and never reached Completed. The loop now moves on to its next element, whichever node the body ends on

- **Long Loops Hit the Processing Limit**: Loops over a few hundred elements stopped with "Max processing depth exceeded". Iterations no longer nest, so long array and map loops run to the end

- **Set Array With Nothing Wired Emptied the Variable**: A Set Array node whose array input is not connected now leaves the variable as it is

- **Chained Array Operations Read an Empty Result**: An array operation fed by another array operation's output received nothing for some element types

- **A Dead End Left No Line on Screen**: Advancing a line into a branch that leads nowhere now keeps the current line usable instead of leaving the dialogue with nothing to show

- **Exit Flows Inside Loops Cleared the Loop**: A called script that ends on an exit route nobody connected stays in the script and keeps its loops intact

- **Variables Sharing a Name Across Scopes**: A local and a global variable with the same name could be confused. The node's own scope now decides which one it reads and writes, and change events report the right scope

- **Unwired Run Script Parameters**: A parameter left unconnected now passes false, 0, an empty string or an empty array, as it does in StoryFlow Editor, instead of the called script's default
